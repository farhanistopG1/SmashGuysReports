# Smash Guys Reports

One command combines Daily Sales Summary, Menu Mix, and Removed Charges:

```bash
python3 body.py 2026-07-28
```

Before the first run, copy `.env.example` to `.env` and enter the authorised
Restroworks credentials. If this directory is moved to the Desktop beside
`SmashGuysAutomationV1`, the runner can also use the existing V1 `.env`.

The original V1–V3 folders are not changed.
